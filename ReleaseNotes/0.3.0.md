# MacGacha4Life 0.3.0

First MacGacha4Life release, based on MacGacha 0.2.6 by deruta74.

- New native look: system sidebar with each game's status, full-bleed art and Liquid Glass cards. ⌘1–⌘3 switch games.
- Quick facts over the art: graphics backend, frame limit and Game Mode. Click them to open the game's settings.
- New Help & Performance panel: search the web for a game's problems, see known issues, report a problem and check the settings that affect performance.
- Optional Metal performance overlay in each game's settings (off by default).
- Quick Play from the menu bar.
- The launcher shows still images while a game runs and in Low Power Mode, so it never competes with the game for the GPU.
- Smaller minimum window size, with a compact layout for narrow windows.
- New app icon.
