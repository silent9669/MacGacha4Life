# MacGacha4Life 0.4.0

A new layout built around a Home page and a page for each game.

- Home: every game as a card with one-click Play, your total playtime, free disk space, the state of your dependencies and the latest HoYoPlay events.
- Each game has its own page: full-bleed art with a glass action bar, then cards for graphics, frame limit and the performance overlay, playtime and last played, size on disk, and events.
- Dependencies, Help & Performance and Diagnostics are pages in the sidebar instead of sheets.
- A game's backend, frame limit and Game Mode sit in the window toolbar.
- Playtime and last played are tracked for each game.
- Releases are now published automatically once CI passes.
