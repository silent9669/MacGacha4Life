# MacGacha4Life 0.5.0

- Each setting shows a green, yellow or red dot for how hard it works your Mac, with a total on the game page and in the settings sheet.
- The game page has a Version card: the installed version, a manual update check and HoYoPlay's Version Info.
- Events show the newest posts of all three games. Genshin Impact and Zenless Zone Zero were missing because their posts are announcements, not activities.
- Settings moved into tabs: General, Games, Updates and About.
- Dependencies lists what each game needs with a Set Up button, and which games use each dependency.
